# PDF Extractor

A Claude Code skill that extracts and summarises content from PDF documents — tables, figures, key data, and action items.

## What it does

- Identifies document type
- Reproduces all tables in structured Markdown
- Extracts key figures, statistics, and named entities
- Lists action items and deadlines
- Flags unusual content for review

## Install

**Claude Code:**
```bash
mkdir -p ~/.claude/skills/pdf-extractor
# Download and copy SKILL.md into the folder
```

Or use the [AI Asset Hub](http://localhost:3000) to install with one click.
